# Audit protocol

Use for AUDIT. Audit is an explainable inspection of a supplied draft, not an AI-detector score and not a mandate to rewrite.

## 1. Establish audit scope

Identify the text, section, target concern, available user-language profile, reference corpus or learning profile, and whether markup or scientific locks are present. State `Insufficient evidence` for requested reference-consistency claims when no comparable reference material is available.

## 2. Inspect the relevant dimensions

Assess only dimensions within scope:

```text
scientific-meaning and claim-scope preservation
terminology consistency and prohibited synonymization
citation and LaTeX integrity
vocabulary drift from the user's established natural language
unnecessary lexical or syntactic complexity
claim-strength drift, hedging, and unjustified emphasis
sentence cohesion, paragraph job, and information order
reference consistency and source-transfer independence
over-editing relative to the requested revision budget
```

## 3. Report evidence-backed findings

For each material finding, provide: location; observation; why it matters; evidence label; severity (`critical`, `material`, `minor`, or `no issue`); and the smallest safe correction or `Keep`. Never infer scientific invalidity from prose alone.

## 4. Separate findings from preferences

An actual error, integrity risk, ambiguity, or unsupported reference claim is a finding. A stylistic alternative with no clear benefit is a preference; do not present it as a defect. Summarize what is already working so the audit does not imply that every sentence requires change.

## 5. Close with limits

State which claims were not checked—for example factual correctness, citation validity, compilation, or field-wide convention—unless those checks were actually performed with suitable evidence.
