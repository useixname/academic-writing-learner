# Application protocol

Use this complete procedure for APPLY. It turns an explicitly available learning profile and user draft into a minimum sufficient revision without changing scientific meaning.

## PHASE 0 — Establish revision context

Identify target text, target section, user objective, requested output format, revision budget, available source papers or current-context learning profile, user-language evidence, and protected markup/content. If scientific information is missing, do not invent it. First complete every safe, useful revision that does not require the missing fact, and mark the unresolved point explicitly. Ask a focused question only when the requested revision cannot meaningfully proceed without that information.

## PHASE 1 — Lock scientific meaning

Create the proposition, terminology, and markup locks in [manuscript integrity](manuscript-integrity.md). Treat these locks as the acceptance criteria for every wording change.

## PHASE 2 — Identify rhetorical role

Assign the passage and each material sentence a label from [rhetorical functions](rhetorical-functions.md). Separate what the user claims from how the passage currently presents it.

## PHASE 3 — Diagnose actual writing problems

Check only for concrete issues: grammar, ambiguity, inaccurate claim calibration, terminology inconsistency, broken cohesion, poor information order, inappropriate section fit, needless lexical or syntactic complexity, unsupported reference attribution, or user-requested restructuring. Apply [readability and syntax](readability-and-syntax.md) and [user language profile](user-language-profile.md). Do not treat difference from model preference as a problem.

## PHASE 4 — Retrieve relevant learned patterns

From a supplied source or explicit current-context learning profile, retrieve only patterns matching the same section, rhetorical role, and need. Check `appropriate_when`, `avoid_when`, confidence, corpus scope, and transfer level. If none applies, do not simulate reference evidence.

## PHASE 5 — Decide whether editing is necessary

Use `Keep` if the sentence is accurate, clear, natural, role-appropriate, and consistent with terminology and budget. Otherwise select the lowest intervention that resolves the identified problem: correction, local edit, sentence restructuring, or paragraph restructuring.

## PHASE 6 — Produce the minimum sufficient revision

Preserve all locks. Prefer conceptual transfer before structural transfer before lexical transfer. Use user-established terminology and natural vocabulary whenever equally effective. Do not imitate source sentences or produce a substitute draft that exceeds the budget without labelling it as optional.

## PHASE 7 — Verify semantic preservation

Compare each revised proposition with PHASE 1. Check entities, method names, directionality, quantities, comparisons, conditions, qualifiers, uncertainty, causal relation, and citation attachment. Restore the original or flag uncertainty if any item drifts.

## PHASE 8 — Verify terminology and vocabulary consistency

Apply terminology and vocabulary-drift checks from [user language profile](user-language-profile.md). Technical repetition is acceptable. Remove unneeded lexical upgrades, vague abstract nouns, and AI-like syntactic inflation.

## PHASE 9 — Verify source-transfer independence and pattern use

Ensure no distinctive source string, image, table content, or unsupported result has been copied. Inspect the final revision for unusual nontechnical multiword overlap with source material, but do not use a fixed word-count or n-gram threshold as the sole criterion. Judge whether phrasing is distinctive, source-specific, and unnecessarily preserved. Necessary technical terms, conventional academic phrases, and required formulaic expressions are allowed; distinctive source-specific phrasing must be independently rewritten. Also check that repeated rhetorical functions do not reuse the same lexical or syntactic scaffold without a local reason. The result may reflect a transferable decision, never the source study's content or voice.

## PHASE 10 — Deliver revision and rationale

Lead with `Keep` or the revision. Then state only material changes, what was intentionally preserved, evidence labels and confidence where reference evidence was used, and unresolved limits. Use [output schemas](output-schema.md) without exposing unnecessary internal records.
