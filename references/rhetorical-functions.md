# Canonical rhetorical functions

Use these stable labels in learning records, comparison, application, and audit. Choose the narrowest label supported by local context. A sentence can have a primary function and, when genuinely necessary, one secondary function; do not invent new labels for ordinary variation.

| Family | Canonical labels | Use when the sentence primarily |
| --- | --- | --- |
| Context | `establish-background`, `establish-importance`, `define-concept`, `summarize-prior-work` | supplies field context, motivation, a definition, or prior progress. |
| Problem framing | `identify-problem`, `state-limitation`, `explain-consequence`, `locate-gap` | identifies a deficiency, explains its effect, or establishes an unresolved need. |
| Contribution | `introduce-solution`, `state-contribution`, `state-scope`, `state-organization` | presents the work's response, contribution, boundary, or roadmap. |
| Method | `define-method`, `justify-design`, `describe-procedure`, `state-assumption` | defines, motivates, or specifies how the work is carried out. |
| Evidence | `motivate-evaluation`, `describe-setup`, `report-result`, `compare-result`, `report-ablation` | frames an evaluation or reports direct empirical evidence. |
| Interpretation | `interpret-result`, `explain-observation`, `qualify-claim`, `discuss-trade-off` | draws a bounded meaning from evidence or discusses a condition or trade-off. |
| Closure | `acknowledge-limitation`, `state-implication`, `summarize-finding`, `conclude` | limits, extends, summarizes, or closes the argument. |
| Cohesion | `transition`, `elaborate`, `contrast`, `cause-consequence`, `problem-response` | primarily connects the current proposition to nearby text. |

## Labeling rules

- Use the evidence family for direct observations or measurements, and the interpretation family for what the author infers from them.
- Use `state-limitation` only if a real limitation is stated; a vague negative adjective is not sufficient.
- Use `compare-result` only if the text compares a stated baseline, condition, or group.
- Use `qualify-claim` when uncertainty or scope is deliberately set, not for any modal verb.
- Record a sentence's function separately from its topic. “Memory” can appear in background, method, result, or limitation prose.

These labels aid analysis; they do not impose a required move sequence on a user's section.
