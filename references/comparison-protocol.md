# Comparison protocol

Use for COMPARE and multi-paper consolidation. Compare only units that share a relevant section, rhetorical function, and task. A raw frequency count alone never establishes a writing convention.

## 1. Define a comparison question

State the candidate pattern, target genre/section/function, source set, and whether the question concerns wording, claim calibration, sentence structure, paragraph strategy, or user-draft fit. Exclude sources that do not contain comparable usable material.

## 2. Count two different things

For each candidate, report both:

```text
raw occurrence frequency: total qualifying occurrences
paper prevalence: number of comparable papers containing the pattern / number of comparable papers inspected
```

When relevant, also report:

```text
same-section prevalence: papers using it in the same section / comparable papers with that section
same-function prevalence: papers using it for the same rhetorical function / comparable function-bearing units
```

Example: “27 occurrences, but in 2 of 15 comparable papers; concentrated in one paper. This is a source-local habit, not a corpus-wide convention.”

## 3. Prevent source dominance

Cap the influence of a paper's repeated occurrences when judging convention. First assess whether each comparable paper exhibits the pattern at least once in the relevant context; use occurrence counts only to describe intensity within a paper. Do not let a long paper, repeated boilerplate, or one author's habit dominate the conclusion.

## 4. Compare alternatives fairly

Treat expressions as alternatives only when they perform the same function under comparable conditions. Preserve differences in claim strength, subject type, section, audience, and task. Do not frame `show`, `suggest`, and `demonstrate` as interchangeable merely because each can precede a clause.

## 5. Conclude with calibrated language

Use `common in the supplied comparable corpus` only for broad paper prevalence with relevant context. Use `repeated in several sources`, `observed in one source`, or `insufficient evidence` where appropriate. Report counter-patterns and corpus limitations. Multi-paper prevalence describes the supplied comparable corpus; it does not establish a field-wide convention unless the corpus is demonstrably broad and representative for that claim. A comparison may legitimately conclude that more than one choice is acceptable.
