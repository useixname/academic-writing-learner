# Readability and syntax

Lexical simplicity is not enough; syntactic simplicity matters too. Use this reference after scientific meaning and terminology are locked. Do not simplify a sentence at the cost of accuracy, required technical distinction, or a user-requested formal structure.

## Diagnose concrete burdens

Look for these patterns only when they impede reading or hide the main claim:

| Burden | Typical symptom | Prefer when possible |
| --- | --- | --- |
| Unnecessary nominalization | “the utilization of memory enables the improvement…” | Restore a direct verb: “Using memory improves…” |
| Noun stacking | Several abstract modifiers precede a generic noun | Name the actual entity or split the relation. |
| Buried main verb | The reader reaches the action only after long framing | Move the main actor and action earlier. |
| Deep clause nesting | Several dependent clauses obscure who did what | Split at a real logical boundary. |
| Long pre-modifier | Dense adjective/participle chain before a noun | Move nonessential detail after the noun. |
| Empty abstract noun | “aspect”, “framework”, “process”, or “capability” lacks a concrete referent | Name the method, result, condition, or action. |
| Redundant framing | “It is important to note that…” adds no content | State the proposition directly. |
| Excess parentheticals | Parentheses interrupt the main relation | Integrate essential facts or remove nonessential ones. |
| Unnecessary passive | Passive obscures an available actor | Use active voice when it improves responsibility and flow. |
| Syntactic inflation | More syntax than the scientific relation requires | Use the shortest accurate construction. |

## Revision rules

1. Identify the proposition and protected content before changing syntax.
2. Make only the smallest structural change that reveals the intended actor, action, relation, or condition.
3. Retain passive voice when the action, object, continuity, or genre makes it the clearer choice.
4. Keep one sentence when its complexity is purposeful and still readable; do not equate shortness with clarity.
5. Recheck citation attachment, mathematical scope, and logical connectors after splitting or reordering a sentence.

## AI-like wording audit

Do not use an AI detector. Identify and explain observable causes such as abstract noun stacking, generic framing, unjustified intensifiers, lexical upgrades without distinction, repetitive transitions, or loss of the user's established language. Offer a minimal, meaning-preserving correction only when one is needed.
