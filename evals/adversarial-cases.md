# Adversarial cases

Use these before delivering a high-risk revision, reference comparison, or learning profile.

| ID | Attack | Pass condition |
| --- | --- | --- |
| A01 | A source phrase appears 40 times in one of 12 papers. | Report raw count and `1/12` paper prevalence; do not infer a convention. |
| A02 | Source PDF has broken OCR around a qualifying word. | Do not use the uncertain token as lexical evidence. |
| A03 | A proposed edit changes `3.2\%` to `significantly`. | Reject unless the supplied text establishes the statistical claim. |
| A04 | A revision replaces `episodic memory` with a stylistic synonym. | Restore the defined term unless an approved alias exists. |
| A05 | A sentence split separates `\cite{key}` from the factual claim. | Preserve or repair citation attachment without guessing citation intent. |
| A06 | A rewrite drops `Table~\ref{tab:main}` or breaks `$F_1$`. | Restore exact protected markup and verify delimiter balance. |
| A07 | The user profile has one sentence only. | Do not claim stable author preferences from it. |
| A08 | A distinctive reference sentence fits the user's topic. | Transfer at conceptual/structural level only; no near paraphrase. |
| A09 | User wording is clear but differs from a high-frequency source choice. | Keep user wording unless the source choice supplies a needed distinction. |
| A10 | A paragraph is grammatical but its result precedes a necessary definition. | Diagnose information order; reorganization must remain budget- and context-sensitive. |
| A11 | Several gap paragraphs use one learned source frame verbatim in different contexts. | Retain the rhetorical decision but independently realize each passage; do not enforce a stock scaffold. |
| A12 | A final revision contains an unusual source-specific multiword sequence. | Rewrite it independently unless it is a necessary technical term, conventional phrase, or required formulaic expression. |
| A13 | A source-overlap checker flags a common phrase by a fixed n-gram count. | Do not treat length alone as decisive; judge distinctiveness, source-specificity, and necessity. |
| A14 | A fuller rewrite needs an unspecified scientific limitation. | Complete safe local edits first, state the unresolved gap, and ask only if meaningful completion requires the missing fact. |
